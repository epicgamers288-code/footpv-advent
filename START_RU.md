# Публикация адвента FOOTPV через браузер
1. Распакуйте ZIP. Создайте приватный репозиторий на https://github.com/new и загрузите содержимое распакованной папки. На верхнем уровне должны быть render.yaml, Dockerfile, client и server. Нажмите Commit changes.
2. Откройте https://dashboard.render.com/ и выберите New → Blueprint. Разрешите доступ к этому репозиторию, выберите его и ветку с файлами.
3. В форме задайте BOT_TOKEN для нужного бота и ADMIN_IDS для администраторов. Можно указать 0 для первой проверки без админки и заменить через Environment позднее. Для нескольких администраторов укажите их числовые Telegram ID через запятую. Токен вводите в секретное поле Render. DATABASE_URL будет создан автоматически.
4. Проверьте тарифы в форме и запустите развёртывание. В этом шаблоне указаны Free для двух ресурсов. Бесплатная база действует 30 дней, веб-сервис засыпает при отсутствии трафика. Перед мероприятием выберите постоянные тарифы для базы и приложения и синхронизируйте значения plan в render.yaml.
5. Дождитесь Live у Web Service. Скопируйте HTTPS-адрес с его страницы. В обычном браузере появится «Раздевалка», по пути /api/health будет ответ ok.
6. Отправьте BotFather главный HTTPS-адрес сервиса в ответ на запрос Mini App URL. Откройте приложение кнопкой в профиле того бота, чей токен указан в Render. До 11 декабря закрытые коробки соответствуют расписанию.
Для закрытой репетиции с календарём используйте отдельного бота. Перевод времени в этой публичной сборке отключён. Команды в чате подключаются в существующем диспетчере бота отдельно, кнопка открытия работает через Main Mini App.
