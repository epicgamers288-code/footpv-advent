# Обновление существующего адвента
Распакуй архив. В репозитории footpv-advent открой ветку существующего сервиса Render. В корень загрузи папки client и server и файл Dockerfile. Если сервис уже работает, сохрани его действующий render.yaml и переменные окружения. design-source.zip содержит редактируемые исходники интерфейса и графики.
После Commit changes дождись Live. При отключённом автоматическом развёртывании открой сервис в Render и нажми Manual Deploy → Deploy latest commit. Затем заново открой мини-приложение из профиля бота.
