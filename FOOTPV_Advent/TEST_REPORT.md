# Проверки восстановленной сборки 0.2.0
24 ноября 2026. Проверен код, включённый в этот ZIP. Сервер работал локально с настоящей базой PostgreSQL 19, отдельной от рабочего контура. Для воспроизводимости Node и Rust зависимости зафиксированы в package-lock.json и Cargo.lock.

| Проверка | Фактический результат |
|---|---|
| TypeScript и production bundle Vite | Сборка завершена. Входной JS около 76 КБ gzip. Phaser загружается при входе в матч. |
| Rust | Сборки обычного и репетиционного API. Три модульных теста: подпись и возраст Telegram initData, границы распределения колеса, положительные и отрицательные действия во всех 10 играх. |
| Все 20 дверец | Проверены 20 переключений даты, раскрытие текущего расписания, открытие в 09:00 и продолжение игры до 09:00 второго дня. |
| Попытки | 30 стартов за сезон. Повтор активного старта вернул тот же UUID. Повтор действия с тем же порядковым номером не изменил результат. Четвёртый старт отклонён во всех 10 периодах. |
| Колесо | По четыре параллельных запроса в каждый из 20 дней. Все ответы за день совпали. Число билетов совпало с суммой уникальных наград. Перебраны все 100 целочисленных исходов генератора: 40/30/20/8/2. |
| Рейтинги и билеты | Проверены 10 закрытых таблиц, лучший результат, одинаковое место при полном равенстве и дополнительный критерий. Повторное закрытие не меняло начислений. Отдельная SQL-фикстура достигла максимума 150 билетов. |
| Тестовый розыгрыш | Снимок доступен до раскрытия seed. Два приза, два разных победителя. Независимый Python-пересчёт совпал с ответом Rust. Повторный запрос вернул тот же протокол. |
| Перезапуск API | После остановки процесса и запуска с прежней базой действовали сессия и активный UUID. Награда колеса сохранилась. Фоновая задача закрыла пропущенный период и начислила билеты. |

| Модуль бота | Проверены 8 точек входа, обычный /start, неизвестная команда и групповой чат. Внешние сообщения не отправлялись. |

## Что ещё проверить перед публичным стартом
- Docker Compose с образом PostgreSQL 18, DNS, выдачу сертификата Caddy и восстановление рабочего бэкапа на выбранном хосте. Здесь компоненты запускались напрямую, без Docker daemon.
- Реальный вход и доставку уведомлений в закрытом контуре Telegram. Тест браузера использовал локальный вход и эмуляцию мобильного размера. Физические Android, iOS, Telegram Desktop и стабильные 60 FPS требуют отдельной проверки.
- Нагрузку при одновременном старте большой группы и влияние сетевой задержки на игры с точным таймингом. Сервер проверяет игровые действия, но не может установить, что все действия вводил человек.
- Провести игровую приёмку с тренером. Отдельно согласовать список призов, текст правил и порядок обработки данных с организатором. Публичного запуска и реального отбора победителей не было.

Обычный бинарник дополнительно запущен с отдельной локальной базой и синтетическим токеном бота. Независимо сформированная в Node.js подпись прошла проверку через HTTP, сервер вернул правильную роль. Тестовый login и перевод часов были отклонены. Обе сборки отказались стартовать при перекрёстном подключении к рабочей и репетиционной базам.
